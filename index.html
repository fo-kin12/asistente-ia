¿Cómo centro un div con flexbox?

Convierte el contenedor en flex y centra en los dos ejes:

.contenedor {
  display: flex;
  justify-content: center; /* eje horizontal */
  align-items: center;     /* eje vertical */
}

📄 Fuente: MDN Web Docs · Conceptos básicos de flexbox
